# 2026-07-31

## 设计语言分析与方向建议

- 完成项目设计语言现状分析（纸墨编辑风 paper-ink）：配色 #f8f7f4 纸底 + #e45435 印章红、Plus Jakarta Sans + JetBrains Mono、圆角 16/12/10、负扩散阴影、动效全 token 化。
- 核心发现：token 架构（--site-* 用户色 → color-mix 派生 → 语义角色）是最大资产，换主题组件零改动；--font-serif 宋体衬线声明了但几乎未用；极小标签 0.42-0.56rem 有可读性风险；无深色模式。
- 提出四个方向：A 深色墨玉（主推）/ B 冷灰极简（可作 A 浅色配套）/ C 极光玻璃（只建议 hero 试点）/ D 编辑风深化（低成本备选）。
- 交付物：docs/design-language-review.md（含各方向 CSS token 配方与快速改进清单）。
- 项目设计语言规范来源于 /Users/lrwei91/Documents/Project/project-standards/design/。

## A+B 双主题实施（用户拍板"按推荐的继续"）

- 架构：ThemeConfig 加可选 colorScheme（zod 默认 light）；data-color-scheme 挂在 .public-site 与 .admin-studio__canvas；后台外观面板新增浅色/深色切换。
- B 冷灰浅色成为新默认主题（#fafafa/#111113/#6e6e73/#e8e8ea，soft 阴影扁平，radius-panel 12px）；用户 local-data 里的旧纸墨配置会被 normalizeThemeConfig 自动迁移到新默认（既有行为）。
- A 深色墨玉：[data-color-scheme="dark"] token 覆盖层，seal 由 color-mix(site-primary 74%, white) 提亮保色相；body:has() 防 overscroll 白边。
- 快速改进：~30 处字号抬到 0.625rem 下限（intro 装饰稿除外）、按钮 :active scale(0.98)、三处 token 块抽共享基类、衬线保留给签名（e2e 契约要求标题无衬线）。
- 后台外壳暂保持浅色（TSX 内有硬编码色值，深色化是后续项）；sonner Toast 深色未适配。
- 验证：vitest 80/80、tsc、eslint、e2e 14/14（含新增 dark-scheme.spec.ts 契约）。
- 注意：Playwright 启动清理 test-results 会触发 safe-delete 批量护栏，需先手动移走该目录。
