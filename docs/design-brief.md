- 项目：林荣威个人主页与配套内容后台
- 负责人：lrwei91
- 更新时间：2026-08-01
- 当前阶段：瑞士技术编辑风作品集、明暗系统主题与克制动效
- 权威设计基线：`project-standards/design/`；本文件记录 Bio Blocks Studio 的项目级视觉适配

## 目标与用户

- 业务目标：让访客快速识别主页主人、专业方向与代表性经历，并能继续查看项目或发起联系。
- 目标用户：招聘方、潜在合作方、同行与熟人访客。
- 首要任务：确认“是谁、做什么、有哪些可信经历与作品”。
- 主要动作：从欢迎封面进入个人资料，浏览经历与项目，通过邮箱或社交入口联系。
- 不在本次范围：公开注册、评论、访问统计、多管理员协作。

## 信息层级

1. 欢迎封面中的姓名、职业方向、个人主张与“进入主页”动作。
2. 个人资料、工作经历、技能和项目。
3. 旅行、近况、媒体与照片等生活内容。

欢迎页是明确的产品保留项。它采用正文流中的 `100dvh` 封面，而不是模态门禁：个人主张、姓名、职业方向、真实工作台主视觉和“查看经历与作品”动作完整落在首屏。个人项目位于首屏下方的独立作品章节，不再挤占 hero 信息栈。“查看经历与作品”使用原生 `#profile` 锚点，JavaScript 失效、动效关闭或减弱动效时仍完整可用。

## 视觉系统

- 视觉主张：冷银纸面承载信息、石墨黑建立层级、朱橙只强调品牌、焦点和主要动作。构图采用瑞士技术编辑语言，通过非对称网格、强排版和开放式信息分组减少卡片依赖。
- 默认角色：背景 `#F4F5F6`、表面 `#F9FAFB`、正文 `#16181D`、次要文字 `#59616A`、边框 `#D8DDE2`、朱橙 `#E45435`。深色模式使用 `#0E0F12` 与冷白正文，并保留同一强调色色相。
- 排版：姓名、章节、卡片标题、正文和 UI 均使用 Plus Jakarta Sans 与系统中文无衬线；只有个人格言保留系统宋体；短标签继续使用 JetBrains Mono。
- 表面：默认面板和卡片使用 8px 圆角，控件使用 6px 圆角；常规内容不使用阴影，以留白和细分隔线组织层级。
- 前后台一致性：后台预览直接使用公开页主题映射；登录页、工作台、资料卡、表单、工具栏和弹层共用技术编辑语义。
- 颜色模式：提供浅色、深色和跟随系统三种选项，默认跟随系统；公开页、后台工作台和预览画布保持同步。

## 交互与动效

- 欢迎封面不锁定页面、不等待计时器、不遮蔽底层语义。
- 章节直接使用中文标题，不使用编号 eyebrow；同组内容按阅读顺序轻微错峰，主要入场时长控制在 360–520ms，位移控制在 8–12px。
- 工作经历绘制时间线和节点，旅行地图按省份渐进描边与填色；项目、技能、豆瓣和照片卡片只使用短促的轻微位移、边框与箭头反馈。
- 顶部导航通过 `IntersectionObserver` 同步当前章节，不监听逐帧滚动；印章红下划线只承担位置提示。豆瓣 Tab 使用滑动指示线和短促内容淡入。
- 详情和照片弹层进入后聚焦关闭按钮，Tab 在弹层内循环，Escape 关闭，关闭后回到触发控件；背景滚动和交互均被隔离并在退出时恢复。
- 弹层遮罩淡入、面板轻微上移，关闭时间短于打开时间。
- 复制、分享和语言切换只有在真实成功后显示成功状态；失败保留页面上下文并给出错误提示。
- 页面不使用持续装饰动画；首屏和内容章节只做一次性层级揭示。
- 所有新增入场动画受“启用动画”设置控制；`prefers-reduced-motion: reduce`、JavaScript 关闭或 Observer 不可用时关闭非必要动画和平滑滚动，直接保留最终静态状态。

## 响应式与无障碍

- 个人信息、章节标题与对应模块共用统一页面容器；正文继续使用内部可读宽度约束。片单使用横向滚动带，项目使用开放式纵向作品索引。
- 860px：欢迎页双栏转单栏，主视觉控制在可视区域内。
- 940px：主页双栏转单栏，导航收起次要链接。
- 640px：卡片、媒体和弹层进入手机布局；头像舞台收紧，分享与返回顶部变为纯图标并避开安全区域。
- 521–767px：核心技能保持两列；520px 及以下改为单列并取消固定行高，避免文字裁切。
- 420px：时间轴保留可读日期宽度，仅收起公司 Logo 等次要装饰。
- 验收视口：320、390、768、1024、1440 CSS px；同时检查无脚本、减弱动效、键盘弹层和 200% 缩放。
- 页面只保留姓名为主标题；拆分动效文案提供完整可访问名称。
- 普通小文本使用 `--text-subtle`，目标对比度至少 4.5:1。
