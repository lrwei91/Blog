# 个人主页设计简报

## 基本信息

- 项目：林荣威个人主页与配套内容后台
- 负责人：lrwei91
- 更新时间：2026-07-27
- 当前阶段：纸墨编辑风实现与无障碍修订
- 权威设计基线：`project-standards/design/`；本项目显式采用 `project-standards/design/themes/paper-ink.md`

## 目标与用户

- 业务目标：让访客快速识别主页主人、专业方向与代表性经历，并能继续查看项目或发起联系。
- 目标用户：招聘方、潜在合作方、同行与熟人访客。
- 首要任务：确认“是谁、做什么、有哪些可信经历与作品”。
- 主要动作：从欢迎封面进入个人资料，浏览经历与项目，通过邮箱或社交入口联系。
- 不在本次范围：公开注册、评论、访问统计、多管理员协作。

## 信息层级

1. 欢迎封面中的姓名、职业方向、个人主张与“进入主页”动作。
2. 个人资料、工作经历、技能和项目。
3. 旅行、近况、媒体与照片等生活内容。

欢迎页是明确的产品保留项。它采用正文流中的 `100svh` 封面，而不是模态门禁：姓名和职业方向直接出现在首屏，“进入主页”使用原生 `#profile` 锚点。JavaScript 失效、动效关闭或减弱动效时，内容和动作仍完整可用。

## 视觉系统

- 视觉主张：暖纸承载信息、深墨建立层级、单一印章红强调关键动作。
- 语义角色：`paper / card / ink / text-subtle / rule / seal`；边框色不再兼任正文色。
- 排版：正文和 UI 使用可配置无衬线栈，中文标题使用系统宋体回退，短标签使用等宽字体。
- 表面：细边框、小圆角、常态弱阴影或无阴影；主题配置统一控制卡片圆角、阴影与字体。
- 前后台一致性：后台画布使用与公开页相同的主题映射；登录页和工作台使用同一纸墨语义。

## 交互与动效

- 欢迎封面不锁定页面、不等待计时器、不遮蔽底层语义。
- 详情和照片弹层进入后聚焦关闭按钮，Tab 在弹层内循环，Escape 关闭，关闭后回到触发控件；背景滚动和交互均被隔离并在退出时恢复。
- 复制、分享和语言切换只有在真实成功后显示成功状态；失败保留页面上下文并给出错误提示。
- 连续动画仅用于欢迎封面的环境层和头像状态点；离屏或页面隐藏时暂停。
- `prefers-reduced-motion: reduce` 下关闭非必要动画和平滑滚动，直接保留最终静态状态。

## 响应式与无障碍

- 个人信息、章节标题与对应模块共用统一页面容器；正文继续使用内部可读宽度约束；1180px 以下项目和媒体改为两列。
- 940px：主页双栏转单栏，导航收起次要链接。
- 640px：卡片、媒体和弹层进入手机布局。
- 420px：压缩时间轴次要装饰。
- 验收视口：320、390、768、1024、1440 CSS px；同时检查无脚本、减弱动效、键盘弹层和 200% 缩放。
- 页面只保留姓名为主标题；拆分动效文案提供完整可访问名称。
- 普通小文本使用 `--text-subtle`，目标对比度至少 4.5:1。
